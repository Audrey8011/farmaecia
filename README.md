# Farma&Cia

Projeto de loja virtual Farma&Cia em ASP.NET Core MVC, com SQL Server LocalDB e interface pronta para uso.

## Início rápido

- **Pelo Visual Studio:** abra `FarmaECia_Interface_Basica\FarmaECia_Interface_Basica\FarmaECia.sln` e pressione `F5`.
- **Pelo terminal:** execute `iniciar-site.bat` nesta pasta.
- **Conta administrativa de teste:** `admin@farmaecia.local` / `Admin@12345`.

O site fica disponível em `http://localhost:5186`.

## Estrutura desta pasta

| Caminho | Conteúdo |
| --- | --- |
| `FarmaECia_Interface_Basica/` | Solução e projeto ASP.NET Core (`FarmaECia.sln`). |
| `Prototipo-HTML/` | HTML/CSS original que estava em `Desktop\site`, mantido como referência. |
| `iniciar-site.bat` | Atalho para restaurar, compilar e executar o site pelo terminal. |
| `parar-site.bat` | Encerra a instância local do site nas portas 5186/7186. |
